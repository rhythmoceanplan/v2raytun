# Security Policy

## Supported versions

| Release | Supported |
| :--- | :--- |
| Latest on [Releases](../../releases/latest) | yes |
| Older tags | no |

## Reporting a vulnerability

Security issues in the **upstream application** should be reported to the
official project:

- Repository: [LXST-CODE/v2RayTun](https://github.com/LXST-CODE/v2RayTun)
- Website: https://v2raytun.com/

For problems with **this mirror** (broken download, wrong archive name,
README only):

1. Open an issue in this repository with steps to reproduce
2. Do not post exploit details publicly before a fix is available

## Safe download

- Use only files from **Releases → Latest**
- Verify the archive name matches **`v2raytun_windows.zip`**
- After extract, run **`v2raytun_windows.exe`** from the folder inside the zip
