# Installation (Windows)

## Requirements

- Windows 10 or 11 (64-bit)
- No Python required for the portable build

## Steps

1. Open **[Releases → Latest](../../releases/latest)**
2. Download **`v2raytun_windows.zip`**
3. Extract the archive to any folder (e.g. `Downloads` or `Programs`)
4. Run **`v2raytun_windows.exe`** inside the extracted folder

## SmartScreen

Windows may show SmartScreen on first launch:

1. Click **More info**
2. Click **Run anyway**

## Updates

Check **Releases** in this repository for newer **`v2raytun_windows.zip`** builds.
